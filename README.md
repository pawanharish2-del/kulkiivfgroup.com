# kulkiivfgroup.com

Website for KULKI IVF Fertility & ART Centre, Jaipur.

## Optimizations Implemented

- **Mobile Responsiveness**:
  - Recreated the mobile nav drawer with a premium slide-in layout and blurred backdrop mask.
  - Collapsed grid layouts (`.grid-2`, `.grid-3`, `.grid-4`, `.faq-grid`, `.form-grid`) to single-columns on mobile screens.
  - Converted the patient timeline into a vertical step list.
  - Patched margin offsets dynamically inside the testimonial slider.
- **Search & Generative Optimization (SEO/GEO/AEO)**:
  - Added `robots.txt` pointing to the XML sitemap.
  - Injected structured JSON-LD data (`Physician` & `MedicalClinic` with geographical coordinates) on main doctor profile, about, and contact pages.
